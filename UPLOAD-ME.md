# Put this on csanchez05.github.io

1. Open the `csanchez05.github.io` repository on GitHub.
2. Choose **Add file → Upload files**.
3. Drag **everything inside this folder** onto the upload area. Keep the `research` and `art` folders.
4. Add `MY_HEADSHOT.png` beside `index.html` before uploading, or upload it afterward.
5. To add artwork later, upload images named `artwork-01.png`, `artwork-02.png`, and `artwork-03.png` inside the `art` folder.
6. Commit the upload to the repository's default branch. GitHub Pages normally refreshes within a few minutes.

The page is plain HTML, CSS, and JavaScript. No build command, package installation, or GitHub CLI is required.
